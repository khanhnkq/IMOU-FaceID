Chụp ảnh gửi Telegram ngay

Kiến trúc (vì sao không host full lên Vercel)

  1. Ở nhà: PC/Raspberry Pi đọc RTSP từ cam → nhận diện → gửi Telegram. Bắt buộc ở nhà vì chỉ mạng nhà mới thấy cam.
  2. Trên này (Vercel): trang tĩnh giới thiệu + dashboard. Muốn xem ảnh cảnh báo thì mở Telegram.
  3. Đi xa: Telegram + Tailscale, không cần mở port.

Chạy ở nhà trong 3 lệnh

uv venv --python 3.11 .venv && source .venv/bin/activate
uv pip install -r requirements.txt
.venv/bin/python app_gui.py   # hoặc watch.py để canh 24/7

Điền IP + Safety Code cam vào file .env trước khi chạy. Chi tiết xem README trên GitHub.
